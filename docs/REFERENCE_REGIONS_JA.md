# 参照範囲の指定（パッケージ1.4.1）

人物名、色、服種、テスト画像の位置による分岐は追加しない。既存のReference V1.2とSheet EncodeのID、6つのリスト出力、画像番号、Auto/Manual、Guide OFF、V1/V1.1を維持する。パッケージの版は1.4.1。既存ワークフローの互換用にノード表示名は維持する。

## 生成文

着用衣装は「同じ人物が参照衣装を着ている」と指示し、頭を画面外に置く。首元から衣装の最下端までを含める。参照にある被覆、つながった裾、開口、重なりを保持する。服単体は従来どおり人体なし。手の状態がreferenceの場合、手袋や裸足などの例を無条件に文章へ入れず、参照の被覆を保持する。bare/glovedはユーザーが明示選択した場合だけ使う。

## Sheet Encodeのreference_regions

追加された任意の文字列入力。初期値`{}`は画像全体をそのまま使う。JSONのトップレベルは`character_image`、`reference_image_1`、`reference_image_2`、`reference_image_3`。その下はビューIDまたは`*`をキーとし、値を`[左, 上, 幅, 高さ]`にする。座標は画像全体を0〜1とする。画像番号ではなく元の入力名を指定するため、Guideや参照の採否が変わっても範囲が別画像へずれない。

例（座標は説明用。自分の画像で確認して設定する）：

```json
{
  "reference_image_1": {"*": [0.1, 0.1, 0.8, 0.5]},
  "reference_image_2": {
    "face_front": [0.05, 0.05, 0.4, 0.3],
    "clothing_front": [0.05, 0.05, 0.4, 0.9]
  }
}
```

個別ビューの指定が`*`より優先する。正面と背面が並んだ資料ではそれぞれの範囲を指定できる。何も指定しないビューは画像全体を使う。Batch Out ONでは各出力のビューIDで選ぶ。OFFの混在シートでは同じ画像に必要な範囲を包含する1つの矩形を使い、範囲未指定のビューが1つでもあれば全体を使う。混在シート内でビュー別に画素を隔離するマスクではない。

切り取りはEncoderがCoreへ渡す直前に一度だけ実行する。同じ切り取り画像をCoreの視覚EncoderとVAEへ渡す。縦横比、画素、チャンネルとバッチを保ち、範囲外は画像端で切り詰める。画素が含まれない指定は分かるエラーにする。layout_imageは切り取らない。未採用の画像もEncoderへ追加しない。

参照領域の目視確認にはCoreのCrop ImageとPreview Imageを使える。UIで切り取った画像を使う場合はその出力をDesignerとEncoderの同名入力へ分岐し、同じ画像へのreference_regionsは`{}`にする。自動検出、自動マスク、画像内容からの役割推定は追加しない。

## 解像度の契約

| モード | Batch Out OFF | Batch Out ON |
|---|---|---|
| Auto | 既存AL-1のシート全体サイズ | 基準高1120：顔1024×1024、全身・衣装768×1344、手・足1184×864 |
| Manual | 指定W×Hのシート1枚 | 選択した各ビューを指定W×Hで1枚ずつ |

reference_regionsは入力画像の範囲。resolutionはCoreでの参照再サンプル量。width/heightは出力ラテントの実寸。3つは独立する。切り取り後もresolution=1024なら各参照は約1MPへ調整されるため、切り取りでVRAMが必ず減るとは言わない。元のレイアウトと出力サイズは変更しない。


検証の範囲は[公開検証要約](../verification/gpu_summary_v141.json)と[配布検証](../verification/release_v141.json)を参照してください。
