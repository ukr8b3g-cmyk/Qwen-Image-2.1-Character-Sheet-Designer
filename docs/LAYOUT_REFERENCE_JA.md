# レイアウト画像出力

既存のprompt／width／heightの後にlayout_image（IMAGE）を追加します。画面と同じマネキンPNGの切り出し・配置計算を使い、指定寸法の白背景RGB画像を出力します。座標JSONと説明の繰り返しは生成用promptから除きました。部位指定の原文・適用範囲・優先順位とstate schema v1/v2は維持します。

- use_layout_image=ON：TextEncodeQwenImage21のimage_1へlayout_image、image_2へ人物参照を接続します。画像1は配置、画像2は人物・衣装・画風です。
- OFF（新規入力の既定）：従来どおり人物参照1枚をimage_1へ接続します。layout_image自体はどちらの設定でも出力されます。

同梱3種のworkflowはON、13ノード・17リンクです。配置画像をPreviewImageへも接続しています。resolution=0で配置参照と生成寸法を一致させるため、参照画像の処理負荷は従来の1024設定より増えます。出力を小さくするかresolutionを変更すると負荷を下げられますが、後者は参照と生成の寸法が変わるため配置も確認してください。

## 胸像プロンプトの改善

現在の配置画像とノード内プレビューには、選択したビューごとに黒い長方形の枠を描きます。配置参照ONの編集指示は、完成画像でも黒枠をその位置・寸法・黒色で保持し、枠内の灰色ガイドを人物参照の肌・髪・衣装へ一対一で置換します。枠線の除去は指示しません。チェックを外したビューの枠と編集指示は出力しません。

旧プロンプトは「胸まで」と指定する一方で、左右の胸像の上端・下端を揃える指示も含んでいました。配置PNGは同じパネル内に異なる縦横比の素材を収めるため、左右の胸像の実際の描画範囲は異なります。ONでは文字による再配置を外し、各灰色胸像の描画範囲・胸で切れる下端・上下の余白を保持する編集指示に変更しました。正面は頭と肩をカメラに正対、鼻を両目の中央へ、側面は鼻を画面右へ向けた側面図とします。

参照した一次資料は [Qwen Image 2.1の公式編集プロンプト指針](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/prompt_rewrite/prompts/system_prompt_edit.txt) です。操作を先に書く、キャンバスと素材の役割を画像タグで分ける、保持する人物を言葉で過剰に描き直さない、定型文を一段落にする方針を採用しました。これは公式Prompt Enhancer用の出力指針であり、改行を含む入力がモデルの仕様違反になるという意味ではありません。ユーザーの部位指定は翻訳・整形せず原文を残します。

[公式README](https://github.com/QwenLM/Qwen-Image-2.1) は生成・編集を統合した7Bのモデル、多画像参照、局所編集への対応を説明しています。40 stepsの実行例もありますが、今回の比較は既存の25 steps、CFG 1、euler/simple、同一モデル・seed・参照・出力寸法を固定してプロンプトの影響を見ています。[公式Prompt Enhancer](https://github.com/QwenLM/Qwen-Image-2.1/tree/main/prompt_rewrite) は専用に学習されたQwen3.5-VL 9Bであり、このノードにLLMを追加したりモデルを取得したりはしていません。
